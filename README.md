# frontend-joker

Armado de pedidos para el local de comida Joker: el operario elige un producto, destilda los ingredientes que el cliente no quiere, agrega el ítem al pedido y lo imprime en un ticket térmico de 8cm.

Stack: React 19 + TypeScript + Vite. Sin backend por ahora — productos hardcodeados.

```
npm install
npm run dev
```
